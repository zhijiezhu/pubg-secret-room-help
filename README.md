# 密室助手 使用说明

PUBG 密室点位叠加层。按 **M** 打开地图时，自动把密室点位贴到游戏地图上，并自动识别当前是哪张图。

主界面为一张竖向卡片：顶部状态徽章 → 「当前地图」卡（下拉 + 图钉/相机/锁三个按钮）→ 「叠加层」卡 → 「更多设置」（可展开）。

---

## 一、使用环境

| 项目  | 要求                                 |
| --- | ---------------------------------- |
| 系统  | Windows 10 1809+ / Windows 11，64 位 |
| 游戏  | PUBG，画面设为 **无边框窗口**（独占全屏盖不住叠加层）    |
| 分辨率 | 16:9，地图保持默认满图视图（按 M 打开即是）          |
| 权限  | **必须以管理员身份运行**（否则游戏前台时读不到 M 键）     |

**启动**：解压后双击 `密室助手.exe` → UAC 点「是」→ 主界面出现，右下角托盘出现图标。免安装，重复双击不会开第二个，只会唤出已运行的窗口。

> 解压时整个文件夹保留完整，不要只把 exe 单独拖出来。

## 二、界面功能

### 1. 顶部状态徽章

显示 `叠加中`（叠加层正在显示）或 `待机`。

### 2. 当前地图卡

| 控件      | 功能                                                          |
| ------- | ----------------------------------------------------------- |
| 地图下拉    | 手动选图，9 张地图：艾伦格 / 米拉玛 / 萨诺 / 维寒迪 / 泰戈 / 帝斯顿 / 荣都 / 帕拉莫 / 卡拉金 |
| 密室数量徽章  | 当前地图的密室点位个数                                                 |
| 📌 图钉按钮 | 主界面浮在游戏上、随 M 显隐、鼠标穿透（地图行仍可点）                                |
| 📷 相机按钮 | 从剪贴板读全屏截图，学成该地图的标题模板与边缘签名                                   |
| 🔒 锁按钮  | 锁定 / 解锁当前地图，锁定后自动识别不再切图                                     |
| 识别状态行   | 显示识别来源与结果，例如「画面识别：泰戈（18:05:12 · 模板匹配）」                      |

### 3. 叠加层卡

| 控件             | 功能                                       |
| -------------- | ---------------------------------------- |
| 显示叠加层          | 手动开关叠加层                                  |
| 按 M 键自动显隐（游戏内） | 按 M 出图、再按 M 或 Esc 收起                     |
| M 键状态          | 「M 键监听正常 · 已捕获 N 次」为正常；显示「按键监听不可用」说明权限不足 |

### 4. 更多设置（默认收起）

| 分组   | 项目    | 说明                     |
| ---- | ----- | ---------------------- |
| 外观   | 主题    | 跟随系统 / 深色 / 浅色（下次启动生效） |
| 外观   | 不透明度  | 叠加层透明度 20%–100%        |
| 外观   | 标记大小  | 点位圆点 8–28 px           |
| 外观   | 标记颜色  | 点位颜色                   |
| 显示内容 | 文字标签  | 点位名称                   |
| 显示内容 | 网格    | 地图网格线                  |
| 显示内容 | 蓝圈塔楼  | 蓝圈塔楼标记                 |
| 显示内容 | 目标显示器 | 多屏时叠加层显示在哪块屏           |

### 5. 托盘菜单（右键托盘图标）

- 显示叠加层 / 隐藏叠加层
- 重新识别地图（括号内为当前识别结果）
- 退出

单击或双击托盘图标 = 唤出主界面。点主界面右上角关闭按钮**只是收起**，真正退出走托盘右键 → 退出。

## 三、使用教程（从图钉锁定开始）

### 第 1 步：把窗口放好，打开图钉

1. 拖动主界面标题栏，把它挪到游戏里不挡视线的地方（左上角或右侧空白处都行）。
2. 点「当前地图」那一行最右边的 **📌 图钉按钮**。
3. 打开后主界面就浮在游戏画面上了：跟着叠加层一起按 M 显隐，鼠标点击会穿透到游戏里。
4. 屏幕上会出现提示：`图钉已开 · 鼠标已穿透（顶部地图行可操作）· 按 Ctrl+Shift+P 取消图钉`。

> 想换位置：先按 `Ctrl + Shift + P` 关掉图钉，拖好位置再重新打开。

### 第 2 步：锁定当前地图

锁定 = 这一局不再让自动识别换图，点位稳稳贴在你选的那张图上。

- **手动锁**：确认下拉里是正确的地图，点 **🔒 锁按钮**，图标变成闭合即已锁定。
- **自动锁**：不点也行——识别置信度 ≥95% 时程序会自动锁定，状态行显示「匹配 97%，已自动锁定」。

锁定后识别状态一行显示：  
`地图已锁定 · 自动识别暂停 · 新回放产生时自动解锁（可手动选图）`

### 第 3 步：进游戏，按 M 看点位

- 开局后按 `M` → 叠加层出现，密室点位贴在游戏地图上。
- 再按 `M` 或 `Esc` → 收起。
- 锁定状态下地图不会再变；想换图就手动下拉选，选完再锁。

### 第 4 步：第一局确认识别是否正常

按 M 之后看「识别状态」那一行，它会告诉你结果和来源：

| 显示                            | 含义                    |
| ----------------------------- | --------------------- |
| `画面识别：泰戈（… · 模板匹配）`           | 名称比对成功，这局认得准          |
| `画面识别：荣都（… · OCR）`            | 模板没中，系统认字认出来的，顺手已学成模板 |
| `画面识别：米拉玛（… · 边缘纹理）· 匹配 97%`  | 没有地图名，靠边缘纹理认出并锁定      |
| `未找到回放记录 · 开局 1 分钟内按 M 可自动识别` | 还没有可用信息，下一局开局时再按 M    |

**如果遇到没学过的地图**（识别不出来或明显不对）：

1. 开局 1 分钟内按 `M` 打开地图（名字还在左上角时）
2. 按 `Win + PrtScn` 截全屏
3. 回到助手，**先在地图下拉里选好这张图**
4. 点 **📷 相机按钮**

学完以后这张图就能自动认了，下次不用再教。

### 第 5 步：下一局自动解锁

一局结束会生成新回放。下一局开始前（还在飞机上、没落地时）：

- 按 `M` → 程序读屏幕右上角，看到「0淘汰 0助攻」这种没有「存活」的状态，就判定为开局前，去读一次回放；
- 发现新回放 → 自动解锁，锁图标变回开锁，同时重新识别本局地图；
- 如果右上角已经有「…存活」了，说明已经开局，程序会保持锁定、不去读回放（正常现象）；
- 60 秒内只检查一次，连按 M 不会反复扫。

也可以不等自动：直接点锁图标手动解锁。

### 一局完整的节奏

```
飞机上 / 等待界面   按 M（可选）→ 自动解锁，准备识别新一局
落地 1 分钟内       按 M → 认地图名 → 置信度够高自动锁定
本局中              随时按 M 看点位，锁定保证不被误切
本局结束            生成新回放 → 下一局重复上面三步
```

### 教程里的常见卡点

| 卡点           | 处理                                              |
| ------------ | ----------------------------------------------- |
| 图钉开了，面板点不到   | 这是穿透效果。「当前地图」那一行仍可点；要操作整张面板按 `Ctrl + Shift + P` |
| 锁了但地图选错了     | 点锁图标解锁 → 下拉改图 → 再锁                              |
| 名字消失后按 M 认不出 | 这张图的边缘纹理还没学过，用 📷 教一次（必须全屏截图）                   |
| 开局前按 M 没解锁   | 确认图钉仍开着；确认按 M 时地图是打开状态；60 秒冷却内不重复               |

## 四、快捷键

| 按键                 | 作用                            |
| ------------------ | ----------------------------- |
| `M`                | 打开地图 → 显示叠加层并触发识别；再按关闭地图 → 收起 |
| `Esc`              | 收起叠加层                         |

| `Win + PrtScn`     | 截全屏到剪贴板，配合相机按钮学模板             |

## 五、自动识别与锁定（原理简述）

1. **名称识别**：开局 1 分钟内按 M，从 0.7 秒起每 0.7 秒截一次左上角，先比对已学模板，再用系统 OCR 认字，认出即停。
2. **边缘纹理**：地图名消失后，改比对地图左右两条窄竖带的纹理（≥75% 且明显甩开次优才采纳）。
3. **回放兜底**：只在启动时读一次回放目录；锁定状态下开局前按 M 时才再读一次。
4. **自动锁定**：模板或边缘匹配 ≥95% → 锁定本局，不再自动切图。
5. **自动解锁**：锁定 + 图钉开着时按 M，读屏幕右上角状态字——读到「淘汰/助攻」但没有「存活」= 开局前，此时读一次回放，发现新回放即解锁（60 秒冷却）；读到「存活」= 已开局，保持锁定。

手动选图不受锁定影响，随时可用。

## 六、常见问题

| 现象         | 排查                                              |
| ---------- | ----------------------------------------------- |
| 按 M 毫无反应   | 是否以管理员运行；游戏是否无边框窗口；「按 M 键自动显隐」是否关闭；M 键状态是否「不可用」 |
| 识别不出地图     | 开局 1 分钟后名字消失属正常，靠边缘纹理与锁定；这张图是否还没用相机教过           |
| 锁住后不自动换图   | 锁定在起作用，点锁图标手动解锁，或下一局开局前按一次 M                    |
| 开局前按 M 没解锁 | 图钉必须开着；右上角文字要能截到；60 秒冷却内不重复扫描                   |
| 叠加层位置对不上   | 按 M 重新打开地图复位（按 16:9 满图视图对齐）；多屏时选对目标显示器          |

## 七、文件位置

| 内容   | 路径                                                                                             |
| ---- | ---------------------------------------------------------------------------------------------- |
| 配置   | `%APPDATA%\pubg-erangel-secret-room-helper\config.json`                                        |
| 标题模板 | `%APPDATA%\pubg-erangel-secret-room-helper\templates\<地图代号>.png`                               |
| 边缘签名 | `%APPDATA%\pubg-erangel-secret-room-helper\edges\<地图代号>_N.bin`                                 |
| 日志   | `%TEMP%\srh-log.txt`                                                                           |
| 诊断截图 | `%TEMP%\srh-cap-region.png`（地图名区域）、`%TEMP%\srh-cap-hud.png`（右上角状态）、`%TEMP%\srh-title-last.png` |

`config.json` 中常用项：`demosPath`（回放目录）、`autoDetect`（自动识别总开关）、`floatOnGame`（图钉联动）、`opacity`（不透明度）。删除该文件即恢复默认设置。
